# Portofolio Dianita Aira Diyastuti
Website statis (HTML, CSS, JS) tanpa build/dependensi.

## Ganti foto
Timpa file `assets/foto-dianita.jpg` dengan fotomu (rasio 4:5, nama file sama, huruf kecil semua).

## Deploy ke GitHub Pages
1. Upload semua isi folder ini ke repository (index.html harus di root).
2. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3. Tunggu 1-2 menit, link: https://USERNAME.github.io/NAMA-REPO/
